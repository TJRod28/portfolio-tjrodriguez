# TJ Rodriguez - Personal Portfolio

A portfolio site built from scratch in HTML and CSS for WRIT 40363. It introduces who I am, what I am actively learning, and the work I have created.

**Live site:** https://tjrod28.github.io/portfolio-tjrodriguez/

## Built with

- Semantic HTML5
- CSS with design token, Flexbox, and Grid
- Git and GitHub Pages
- Vanilla JavaScript

## Notes

This portfolio has been a gradual evolving project over the course of the Fall 2026 semester for WRIT 40363. At any given time fonts, texts, colors, or statements can and will change to reflect current expectations or requests. The goal is to build a strong foundation in digital media by gaining skills in CSS, HTML, and JavaScript. This portfolio also serves another purpose, and that is its potential to be used as a professional portfolio to send to future employers alongside a resume.

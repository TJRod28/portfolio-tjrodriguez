# TJ Rodriguez - Personal Portfolio

A portfolio site built from scratch in HTML and CSS for WRIT 40363. It introduces who I am, what I am actively learning, and the work I have made.

**Live site:** https://tjrod28.github.io/portfolio-tjrodriguez/

## Built with

- Semantic HTML5
- CSS with design token, Flexbox, and Grid
- Git and GitHub Pages

## Notes

The accent color and font pairing were chosen in Lab 10.5. Contrast was verified against WCAG AA. This portfolio is a gradual evolving project over the course of this semester. At any given time fonts, texts, colors, or statements can and will change to reflect the current expectations or requests. The goal is to build a strong foundation in digital media by gaining skills in CSS HTML and Java.
